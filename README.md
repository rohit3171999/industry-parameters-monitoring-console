# Industry Parameters Monitoring Console

This project is a starting point for an industrial parameter monitoring system using an Arduino Uno R4 WiFi and a 128x64 SSD1306 OLED display. The current version initializes the display and shows a welcome message.

## Hardware Requirements

To build this project, you will need the following hardware components:

*   **Microcontroller:** Arduino Uno R4 WiFi
*   **Display:** 128x64 SSD1306 I2C OLED Display
*   **Miscellaneous:** Breadboard and Jumper Wires

*   [PlatformIO IDE Extension](https://platformio.org/platformio-ide)

The required libraries are listed in the `platformio.ini` file and will be installed automatically by PlatformIO when you build the project.
*   `adafruit/Adafruit GFX Library`
*   `adafruit/Adafruit SSD1306`

## Wiring Instructions

Connect the SSD1306 OLED display to the Arduino Uno R4 WiFi as shown below. This project uses the I2C communication protocol.

| OLED Pin | Arduino Uno R4 WiFi Pin |
| :------- | :---------------------- |
| VCC      | 5V                      |
| GND      | GND                     |
| SCL      | A5 (SCL)                |
| SDA      | A4 (SDA)                |

**Note:** The I2C address for the OLED display is defined in `src/main.cpp` as `0x3C`. If your display uses a different address, you will need to update the `OLED_ADDR` macro.

## Getting Started

1.  **Clone the repository:**
    ```sh
    git clone <your-repository-url>
    ```
2.  **Open in VS Code:** Open the cloned project folder in Visual Studio Code.
3.  **Connect Hardware:** Connect the components as described in the Wiring Instructions section and plug your Arduino Uno R4 WiFi into your computer via USB.
4.  **Build and Upload:** Use the PlatformIO controls in the VS Code status bar to build and upload the project to your Arduino.
    *   Click the checkmark icon (`✓`) to build.
    *   Click the right-arrow icon (`→`) to upload.

Upon successful upload, the OLED display will show the welcome messages.

## Code Overview

*   `src/main.cpp`: This is the main entry point of the application.
    *   The `setup()` function initializes the Serial monitor and the SSD1306 OLED display. It then prints a few lines of text to the screen.
    *   The `loop()` function is currently empty. This is where you would add code to read from sensors and update the display with real-time data.

*   `platformio.ini`: This is the PlatformIO project configuration file.
    *   It specifies the target board (`uno_r4_wifi`), the framework (`arduino`), and the project dependencies (`lib_deps`).
    *   It also configures the serial monitor and upload port settings.

*   `include/`: This directory is intended for custom header files (`.h`). You can read more about its purpose in `include/README`.
